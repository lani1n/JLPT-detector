# JLPT-detector

## The dataset for JLPT taggin
- The dataset: Bluskyo JMDict_Extended
- Scope & size: Full JMdict + JLPT tags + pitch + furigana
- Format: JSON
- Reason to use: Pre-joining JMdict entries with cleaned JLPT levels, thus no need to write custom dictionary-matching scripts
